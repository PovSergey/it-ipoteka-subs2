# Субсидированная ипотека Сбербанк

Статический калькулятор, готовый для размещения в GitHub и деплоя через RelaxDev.

## GitHub

Основная ветка: `main`.

## RelaxDev

Подключите этот GitHub-репозиторий в RelaxDev, выберите ветку `main` и оставьте включенным автоопределение стека.

Сборка и дополнительные зависимости не требуются: приложение находится в `index.html` в корне репозитория.
